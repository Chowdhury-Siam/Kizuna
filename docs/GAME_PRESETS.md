# Game presets

Open **Game profiles → Game presets**, search a title, then tap it. Kizuna saves and activates an editable copy with the title as its game name. The library contains **58** templates, and the profile store holds **50** custom layouts plus Default. Saving/importing a profile retains its input settings and joystick/touchpad options.

Every template retains two sticks, both triggers, shoulders, ABXY, D-pad, stick clicks, Back and Start. Profiles tune control geometry and XInput response; they do not alter game files, automate actions or add a new input protocol. Use the game's standard Xbox layout, then customise mappings and in-game sensitivity as needed.

Legacy PC editions may expect DirectInput or keyboard input. Use a suitable Steam Input template, a game-supported controller mode or an emulator's mapping page. Console-only entries require an appropriate emulator and your own games. Light-gun/touch interfaces need custom mappings; the gamepad cannot reproduce those automatically. Online-only entries do not restore discontinued services. Mobile-only games are outside the PC controller path.

These are starting configurations, not empirical performance claims. Commercial game gameplay has not been tested here. The preset tests verify complete control coverage, distinct tuning, neutral sticks, unique IDs and JSON import/export; hardware/game acceptance is separate.
